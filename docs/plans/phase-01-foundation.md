# Phase 01: Foundation

## Goal

Ship a reusable baseline batch framework that works without heavyweight model dependencies.

## Deliverables

- Recursive scanning
- Baseline classification
- Rule-based mask generation
- Overlay export
- Telea restoration baseline
- JSON and CSV reporting

## Exit Criteria

- Deterministic CLI behavior
- Stable unit tests
- Clean project defaults
- No sample-bound assumptions in public docs
