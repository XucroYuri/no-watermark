# Security Policy

## Supported Scope

Security issues in the following areas are in scope:

- Local CLI behavior
- Path handling
- Generated file handling
- Provider sidecar execution boundaries
- Unsafe defaults that may expose private inputs or outputs

## Out of Scope

- Third-party model weights
- Vulnerabilities in upstream OCR or inpainting libraries
- Private datasets that are not part of this repository

## Reporting

If you discover a security issue, report it privately to the repository maintainers before opening a public issue.

Include:

- A short description
- Impact
- Reproduction steps
- Suggested mitigation if available
